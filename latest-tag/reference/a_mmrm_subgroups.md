# Formatted Analysis Function for MMRM Subgroups

Formatted Analysis Function for MMRM Subgroups

## Usage

``` r
a_mmrm_subgroups(.formats)
```

## Arguments

- .formats:

  (named `list`)\
  containing the formats for the statistics to use in the MMRM subgroups
  table.

## Value

List of formatted analysis functions to be used in
[`tabulate_mmrm_subgroups()`](https://insightsengineering.github.io/tern.mmrm/reference/tabulate_mmrm_subgroups.md).
